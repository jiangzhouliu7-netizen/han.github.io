保姆级安装教程

从零开始，手把手带你完成安装

0

环境要求

操作系统：macOS / Linux / Windows (WSL2)

Node.js：版本 18 或更高

Claude 账号：需要 Anthropic API Key 或 Claude Pro/Team 订阅

终端：iTerm2 / Terminal / Windows Terminal

1

安装 Claude Code

打开终端，执行以下命令全局安装：

npm install -g @anthropic-ai/claude-code

安装完成后验证：

claude --version   # 应显示版本号

2

登录认证

Claude Code 支持两种认证方式，任选其一：

方式一：Anthropic Console 账号（推荐）

# 直接启动，会自动打开浏览器登录

claude

方式二：API Key

export ANTHROPIC_API_KEY="sk-ant-你的密钥"

echo 'export ANTHROPIC_API_KEY="sk-ant-你的密钥"' >> ~/.zshrc

source ~/.zshrc

API Key 获取路径：console.anthropic.com → API Keys → Create Key

3

首次启动

进入你的项目目录并启动：

# 进入项目

cd your-project

# 启动 Claude Code

claude

首次启动会提示你选择主题和确认权限设置，按提示操作即可。进入后直接输入自然语言指令：

> 帮我分析这个项目的代码结构，然后创建一个 README.md

4

常用命令速查

# 交互模式（默认）

claude

# 单次执行模式（不进入交互）

claude -p "解释这段代码的作用"

# 继续上次对话

claude --continue

# 恢复指定会话

claude --resume

# 查看帮助

claude --help

?

常见问题

Q: 登录后提示 403 错误？

A: 确认你的 Anthropic 账号已开通 API 访问权限，且所在地区支持使用。

Q: 如何让 Claude Code 使用特定模型？

claude --model claude-sonnet-4-20250514

Q: 如何更新到最新版本？

npm update -g @anthropic-ai/claude-code
