保姆级安装教程

从零开始，手把手带你完成安装

0

环境要求

操作系统：macOS / Linux / Windows (WSL2)

Node.js：版本 22 或更高（推荐用 nvm 管理）

OpenAI 账号：需要 ChatGPT Plus / Pro / Team 订阅

Git：已安装并配置好用户信息

1

安装 Node.js

如果你还没有安装 Node.js，推荐使用 nvm（Node Version Manager）来管理版本：

# 安装 nvm

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 重启终端后，安装 Node.js 22

nvm install 22

# 验证安装

node --version   # 应显示 v22.x.x

Windows 用户请先安装 WSL2，再按上述步骤操作。也可直接从 nodejs.org 下载安装包。

2

安装 Codex CLI

打开终端，执行以下命令全局安装：

npm install -g @openai/codex

安装完成后验证：

codex --version   # 应显示版本号

3

配置 API Key

你需要一个 OpenAI API Key（需绑定 ChatGPT Plus/Pro 订阅）：

# 方法一：设置环境变量（推荐）

export OPENAI_API_KEY="sk-你的密钥"

# 写入 shell 配置文件使其永久生效

echo 'export OPENAI_API_KEY="sk-你的密钥"' >> ~/.zshrc

source ~/.zshrc

API Key 获取路径：platform.openai.com → API Keys → Create new secret key

4

首次运行

进入你的项目目录，启动 Codex：

# 进入项目目录

cd your-project

# 启动 Codex（默认使用 o4-mini 模型）

codex

# 或指定模型和自动模式

codex --model o4-mini --approval-mode full-auto

进入交互界面后，直接用自然语言描述你的需求即可，例如：

> 帮我写一个 Python 脚本，读取 CSV 文件并统计每列的平均值

?

常见问题

Q: 提示 "command not found" 怎么办？

A: 检查 npm 全局安装路径是否在 PATH 中。运行 npm config get prefix 确认路径。

Q: API Key 无效？

A: 确认 Key 以 sk- 开头，且账号已绑定付款方式。免费额度不支持 Codex CLI。

Q: 如何更新到最新版本？

npm update -g @openai/codex
